## 이번에 추가로 수정한 오류

1. 부모가 9포기로 늘면 PC 교배 화면의 첫 카드가 왼쪽으로 잘려 클릭할 수 없었다. 가로 스크롤 안의 가운데 정렬을 `safe center`로 바꿨다. 첫 카드가 화면 안으로 들어온 뒤 실제 선택·교배에 성공했다. 모바일의 줄바꿈 배치는 유지한다.
2. PC 홈의 긴 연대기 목록이 고정 스테이지 밖으로 잘려 아래쪽 기록과 일부 메뉴에 접근할 수 없었다. 홈 내용 전체를 스크롤하도록 고쳤다. 기존 기록을 포함한 46개 목록에서 아래쪽 완료 기록과 ‘선생님 안내’를 실제로 열었다. 최종 추가 플레이 후 앱 내 브라우저에는 47개 기록이 있으며 기존 10개 기록은 삭제하지 않았다.
3. 손상된 저장을 불러오다가 실패하면 현재 상태가 중간에 바뀐 채 남을 수 있었다. 단계·모드·정책·계약 인덱스·필수 배열·통계 구조를 확인하고, 실패하면 이전 상태를 복원한다. UI에서도 기존 저장 키를 복원해 잘못된 슬롯에 현재 진행이 저장되는 일을 막는다. 없는 단계, 범위를 벗어난 계약, 누락된 손패·통계, 손상된 부모의 회귀 테스트를 추가했다.
4. 성찰 저장이 실패해도 성공 문구를 보여 주었다. 저장 함수가 실제 성공 여부를 반환하고, 실패 안내와 글 보관 방법을 표시한다. 보고서에는 현재 입력한 성찰을 포함한다. 저장 불가·쓰기 실패·삭제 실패에도 기존 글이 보존되는 회귀 테스트를 추가했다. 새 한국어 안내는 `humanize-korean` light 경로의 검증 게이트를 통과했다(변경률 0%, 등급 B, 자체검증 6/6).

## 이전 수정 재검증

- `save()`가 이번 저장의 성공 여부를 반환하고 최신 저장 실패를 홈 이동 전에 안내한다. 기존 저장이 남아 있더라도 실패를 성공으로 취급하지 않는다.
- 320px 편집 작업대의 네 버튼이 두 줄로 배치된다.
- 염기 변경 직후 키보드 초점이 ‘5번째 염기 A’에 유지된다.
- 종료 화면 납품 기록 끝의 불필요한 구분점이 없다.
