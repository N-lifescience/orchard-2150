# 화면과 문장 개선 기록

2026-10-01

## 읽기와 선택

- 한국어는 띄어쓰기를 기준으로 줄바꿈한다. 긴 단어만 화면 밖으로 넘치지 않게 나눈다.
- 안내 문단 사이에 여백을 넣고, 시즌 수·계약 수·목표를 분리해 표시한다.
- 연대기 범위는 선택한 카드를 확인하고 ‘다음’으로 넘어간다. 전체·짧은 연대기와 단원 게임을 두 영역으로 구분한다.
- 시즌 1~8 표시에서 선택한 범위를 확인할 수 있다.
- 저장 목록에는 과수원 이름, 진행 상태, 모드, 팀, 완료한 계약 수, 마지막 저장 시각을 표시한다. 끝난 연대기는 ‘기록 보기’로 연다.

## 연구 노트

단원별 목차를 왼쪽에, 본문을 넓은 오른쪽 페이지에 배치했다. 목차 제목은 말줄임 없이 줄바꿈한다. 본문은 관찰한 현상, 실제 과학 설명, 게임에서 정한 규칙, 해당 연대기의 관찰 결과 순서로 읽는다. 두 페이지는 따로 스크롤하며, 기록을 고르면 본문 첫 줄로 이동한다. 미발견 기록의 잠금과 성취기준별 보기를 유지했다.

## 카드 연출

카드 선택 광원, 출하 카드의 착지, 꽃가루 입자, 칩·배수가 점수판으로 날아가는 빛, 합계 집계, 계약 완료 배지를 추가했다. 기존 합성 효과음과 맞물려 동작한다. 게임 난수와 별개의 연출 난수를 사용한다. 빠른 연출과 빨리 감기에서는 즉시 정리하며, 동작 줄이기에서는 장식 효과를 생략한다. 하스스톤의 이미지나 음원을 사용하지 않았다.
