# 씨앗 아틀리에 2150 — 게임 설계서 (GDD v1)

> 「생물의 유전」(2022 개정 진로 선택) 수업용. **Balatro 방식 로그라이크 덱빌딩.**
> 원칙: 교과 개념을 설명문이 아니라 **규칙**으로 만든다. 퀴즈 없음. 개념 카드는 겪은 **뒤에** 뜬다.

## 1. 한 줄

2150년, 할머니의 명품 온실을 물려받은 젊은 육종가가 되어 **두 포기를 교배해 씨앗 꼬투리(덱)를 만들고,
거기서 뽑힌 모종 8장 중 5장을 골라 출하(족보)해** 고객의 목표 점수를 넘긴다. 한 판 = 8시즌(앤티) × 주문 3개.

## 2. Balatro ↔ 유전 대응표 (이 표가 게임의 뼈대)

| Balatro | 씨앗 아틀리에 | 교과 개념 |
|---|---|---|
| 덱 52장 | **씨앗 꼬투리 52알** — 주문마다 고른 두 부모의 교배로 만들어짐 | 감수분열·수정이 만드는 자손 분포 |
| 카드의 무늬(suit) 4종 | **빛깔** = 과육색(루비/골드) × 무늬(있음/없음) | 상염색체 멘델 유전(우열) |
| 카드의 숫자(rank) | **당도(Brix) 8~20** = 6개 가산 유전자의 합 | 다유전자유전 → 연속 변이 |
| 핸드 8장, 5장 내기 | 모종 8장 중 최대 5장 **출하** | — |
| 버리기 | **솎아내기** | — |
| 족보 | **수확 족보** (한 쌍 · 당도 계단 · 한 빛깔 · 다섯 쌍 · 완전 균일 …) | 표현형의 균일성은 순계의 증거가 아님. 잡종 1대도 같은 표현형일 수 있음 |
| 덱 강화(카드 추가·제거) | **선발** — 주문이 끝나면 모종 1포기를 온실(부모 칸)에 들인다 | 선발 육종, 자가수분으로 순계 만들기 |
| 조커 | **장인의 비법** 22종 | 개념이 효과로 박혀 있음(아래 6절) |
| 타로 | **연구 시약** (유전자 검사·콜히친·유전자 가위·형질전환·조직배양·비료 …) | 배수체, 전사·번역·유전 부호, LMO |
| 행성 카드 | **품평회 메달** — 족보 레벨업 | — |
| 부스터 팩 | **씨앗 봉투** — 시장 품종 3개 중 1개 (유전자형 모름) | 표현형만 보고 유전자형 추론 |
| 블라인드 3개 | **주문 3개**: 동네 장터 · 고급 식당 · **명품 의뢰인(보스)** | 보스 규칙이 곧 개념 (냉해=비분리 등) |
| 덱 선택 | **브랜드 철학**: 전통 육종 / 정밀 편집 / 바이오테크(LMO) | 생명윤리 의사결정 |

### 가장 중요한 창발 규칙
- 관심 유전자들이 동형접합인 두 부모를 교배 → 자손의 표현형이 균일하기 쉽다. **서로 다른 순계의 잡종 1대는 균일해도 이형접합일 수 있다.**
- 잡종(이형접합) 부모 → 빛깔·당도가 흩어진다 → **당도 계단이 잘 나오지만 한 빛깔은 어렵다.**
- 그래서 플레이어는 목표 족보에 따라 **부모를 고르는 법**을 스스로 익힌다. 설명 없이.
- 한 부모를 두 번 고르면 **자가수분**. 대를 거듭하고 원하는 계통을 선발하면 이형접합 자리가 줄어 순계에 가까워질 수 있다.

## 3. 한 주문(블라인드)의 흐름

1. **교배** — 온실(최대 6포기)에서 같은 종 부모 둘을 고르고 자손 과육색을 예측한다(같은 포기 = 자가수분).
   암수딴그루 종은 암그루×수그루만 된다. 3배체는 불임이라 부모가 될 수 없다.
2. **꼬투리** — 엔진이 감수분열(분리·독립·교차·비분리)로 52알을 만든다. 예측과 실제 분포를 비교한다.
3. **출하 4번 · 솎아내기 3번 · 핸드 8장.** 점수 = (족보 칩 + 카드 칩) × (족보 배수), 비법이 순서대로 발동.
4. 목표 점수를 넘기면 보상(장터 $3 · 식당 $4 · 의뢰인 $5 + 남은 출하 1개당 $1 + 이자 $5마다 $1, 최대 $5). 일반 주문에서 의뢰한 과육색을 출하하면 $2를 더 받는다.
5. **선발** — 이번 주문에 본 모종 중 1포기를 온실에 들일 수 있다(온실이 차면 한 포기를 내보냄).
6. **공방(상점)** — 비법 2개, 봉투 2개, 증축 1개. 새로고침 $5부터.

못 넘기면 게임 끝(Balatro와 같음). 대신 결과 화면에서 **정체 공개**: 내 온실 모든 포기의 실제 유전자형과 계보.

## 4. 종(種) — 같은 엔진, 다른 겉옷

| 종 | 성 결정 | 염색체(2n) | 유전자 |
|---|---|---|---|
| **루미**(가상, 虛) — 둥근 보석 과일 | 양성화(자가수분 가능) | 10 (5쌍) | c1: R 과육색(R 루비 우성 / r 골드) · c2: S 별무늬(S 우성 / s 매끈), B 쓴맛(B 우성 / b) · c3~c5: 당도 Q1~Q6 |
| **별다래**(가상, 키위를 본뜸) — 털 난 타원 과일 | **XY 암수딴그루** — 암그루만 열매 | 8 (3쌍 + XY) | c1: R · c2~c3: Q1~Q6 · **X: L 은빛 잎(L 우성 / l)** · Y: 수컷 결정 |

- 수그루 카드: 꽃만 핀다 → **당도 없음(칩 0), 빛깔은 있음**(꽃잎 색·잎 무늬). 한 빛깔에는 낄 수 있다.
- 아비의 X는 **모든 딸 그루**에게 간다 → 은빛 잎 수그루를 쓰면 딸이 전부 은빛 → 한 빛깔이 쉬워진다. (창발로 배우는 X 연관)

## 5. 시즌 진행(8앤티) — 시즌마다 새 규칙 하나 (코스터: 패턴을 익히면 깨뜨린다)

| 앤티 | 새로 켜지는 것 | 성취기준 |
|---|---|---|
| 1–2 | 루미, 우열·분리·독립, 당도(다유전자), 자가수분·선발 | 12유전01-01, 01-03 |
| 3–4 | 시장에 별다래 등장, 성염색체, 보스 "암그루만" | 01-01 |
| 5–6 | 콜히친(4배체 → 4n×2n = 3배체 씨 없음·불임), 비분리(이수성), 보스 "냉해" | 01-04 |
| 7–8 | 유전자 가위(전사·번역·유전 부호 표로 종결 코돈 만들기), 형질전환(LMO), 꽃가루 유출, 보스 "LMO 표시제 점검" | 02-01, 02-02, 03-04, 03-05 |

수업용 짧은 모드: **빠른 시즌(4앤티)**, **단원 연습**(성염색체 / 염색체 이상 / 유전자 편집 — 해당 앤티부터 시작 온실 제공).

## 6. 장인의 비법(조커) — 개념이 효과다

| 비법 | 효과 | 숨은 개념 |
|---|---|---|
| 할머니의 전지가위 | +4 배수 | — |
| 루비 애호가 / 골드 수집가 | 해당 과육색 모종마다 +3 배수 | 표현형 |
| 무늬 장인 | 무늬 있는 모종마다 +30 칩 | 표현형 |
| 굴절계 | 모종마다 +(당도−10) 칩 | 다유전자 형질 측정 |
| 빛깔 인증서 | 한 빛깔 계열이면 ×3 배수 | 겉모습의 균일성만 인증하며 순계 판정은 아님 |
| 잡종강세 | **이형접합** 모종이 점수 낼 때마다 +2 배수 (반짝이는 걸 보면 누가 잡종인지 알게 됨) | 이형접합 |
| 숨바꼭질 대립유전자 | 두 부모 어디에도 안 보이던 형질의 모종마다 ×1.5 | 분리(숨은 열성) |
| 자가수분 명인 | 자가수분 주문이면 ×2 배수 | 자가수분 → 순계 |
| 교배 일지 | 열성 표현형 모종을 낼 때마다 영구 +1 배수(누적) | — |
| 멘델의 안경 | 겉모습만으로 확실한 유전자형을 자동 표시 | 추론 도구 |
| 퍼넷 노트 | 교배 전 기대 분포를 보여 줌. 교배 뒤에는 모든 플레이어가 예측과 52알의 실제 분포를 비교 | 확률·표본 |
| 꿀벌 군단 | 출하 +1 | — |
| 씨앗 금고 | 이자 상한 +$5 | — |
| 꽃가루 상인 | 수그루를 솎아낼 때마다 +$1 | 암수딴그루 경제 |
| X의 상속자 | 딸 그루가 아비의 X 형질을 보이면 +4 배수 | X 연관 유전 |
| 콜히친 노트 | 씨 없는(3n) 모종이 ×2 (기본 ×1.5) | 3배체 |
| 핵형 현미경 | 이수성 모종의 핵형을 공개하고, 직접 솎아내면 +$1 | 염색체 이상을 관찰한 뒤 선발 |
| 가위 거치대 | 주문마다 유전자 가위 1회 무료 | — |
| 형광 해파리 유전자 (LMO) | 형광 모종마다 ×1.5, 대신 꽃가루 유출 확률 ↑ | LMO·생태계 영향 |
| 기후 적응 온실 | 보스 규칙 약화 | — |
| 할아버지의 향기 노트(전설) | 당도 16 이상 모종의 칩 ×2 | — |
| 조직배양 랩 | 선발 때 1포기 더 들일 수 있음(클론) | 분화·전능성 |

## 7. 연구 시약(타로)

유전자 검사 키트(2장 유전자형 공개) · 콜히친(부모를 4배체로) · 유전자 가위(편집 작업대) ·
형질전환 벡터(형광 유전자 삽입 = LMO) · 조직배양(부모 복제) · 선발 비료(이번 주문만 당도 +2 — **유전 안 됨**) ·
붓 한 자루(이번 주문 교배를 다시 고르기).

**편집 작업대** = 이 게임의 전사·번역 장면. DNA 주형 가닥 → mRNA → 코돈 → 아미노산이 실시간으로 바뀐다.
한 글자 치환·결실로 종결 코돈(UAA·UAG·UGA)을 만들면 효소가 망가져(녹아웃) 쓴맛이 사라지거나 루비가 골드가 된다.
동의 코돈으로 바꾸면 아무 일도 없다(코돈의 중복성). 한 글자 결실은 틀 이동.

## 8. 보스 주문(명품 의뢰인)

냉해(비분리 ×10) · 벌이 없는 날(자가수분만) · 균일성 심사(한 빛깔이 아니면 절반) · 가뭄(당도 −3, 유전 안 됨) ·
과일 심사위원(수그루 출하 불가) · 편식 셰프(한 과육색 무효) · 까다로운 소믈리에(당도 13 이하 무효) ·
LMO 표시제 점검(형광 모종 무효) · 최종: 2150 명품 박람회.

## 9. 브랜드 철학(덱 선택) — 윤리가 규칙으로

| 철학 | 시작 | 제약 |
|---|---|---|
| 전통 육종 아틀리에 | 출하 +1 | 가위·형질전환 사용 불가 |
| 정밀 편집 랩 | 유전자 가위 1개 | 형질전환 불가 |
| 바이오테크 하우스 | 형광 해파리 유전자 | 일부 의뢰인 거절, 꽃가루 유출 |

정답 없음. 결과 화면에서 "내 브랜드가 택한 것과 그 대가"를 돌아본다(03-05).

## 10. 개념 카드(연구 노트) — 겪은 뒤에 뜬다

첫 발생 시 작은 카드가 뜨고 도감에 모인다. 각 카드에 **虛(게임 설정)**·**原作(실제 과학)** 구분.
예: 숨은 대립유전자(분리) · 순계와 균일성 · 자가수분 · 연속 변이 · 환경 변이는 유전 안 됨 · 암수딴그루 ·
X 염색체의 경로 · 배수체 · 3배체와 씨 없는 수박 · 비분리 · 종결 코돈 · 코돈의 중복성 · 틀 이동 · LMO와 유전자 흐름.

## 11. 그래픽·소리

- 배경: WebGL 셰이더(생물발광 소용돌이), 시즌마다 팔레트 변화, 보스 때 붉게 맥동.
- 카드: 절차적 SVG 과일(유전자형 → 모양·색·무늬·크기·광택), 호버 3D 기울기·광택 스윕, 드로우·출하 애니메이션.
- 점수: 칩(청록) × 배수(자홍) 롤링 숫자, 모종마다 +칩 팝, 비법 흔들림, 목표 돌파 시 불꽃.
- 색약 배려: 과육색은 색 + 모양 기호(루비 ◆ / 골드 ●), 무늬는 ✦ 기호로도 구분.
- 소리: WebAudio 합성(드로우·선택·칩 음계 상승·배수·코인·보스). 음소거·동작 줄이기 설정.

## 12. 기술

Vite + TypeScript, 프레임워크 없음(DOM + SVG + WebGL). Vitest로 유전 엔진·점수 테스트.
innerHTML 미사용(요소 생성 함수만). 학생 개인정보 수집 없음(설정·세이브는 localStorage). 외부 API 없음.
