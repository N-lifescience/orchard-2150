# 오차드 2150 — 게임 설계서

## 목표와 핵심 조작

2150년 발렌시아의 가상 육종 회사 오차드를 운영한다. 매니저 레아 모레노가 계약을 안내한다. 부모 선택 → 예측 → 자손 52알 관찰 → 형질 선별·출하 → 다음 세대 선발을 반복한다.

**목표 점수와 필수 형질·수량을 모두 채워야 계약이 끝난다.** 한 시즌에 지역 납품·도시 계약·특별 주문 세 건을 마친다. 마지막 시즌의 최종 계약 완료가 승리다. 점수만 높이는 동일 교배로 후반의 성염색체·배수체·편집 과제를 건너뛸 수 없다.

수업 모드는 실패 원인과 미달 조건을 보여 주고 같은 계약을 다시 준비한다. 부모·시약·돈·난수 상태를 계약 시작점으로 복구한다. 관찰 기록과 발견 개념은 남긴다. 재도전은 출하·솎아내기 횟수와 목표 점수에 도움을 주며 **형질 조건은 유지**한다. 도전 모드는 실패하면 연대기를 끝내고 기록을 보관한다.

## 계약의 흐름

1. 같은 종 부모 두 포기를 선택하거나 자가수분한다. 별다래는 암그루와 수그루가 필요하며 3배체는 부모로 사용할 수 없다.
2. 과육색을 예측한다. 공개된 정상 2배체 부모는 R 자리의 기대 확률을 확인할 수 있다. 비공개 부모·편집·배수성 조건에 단순 멘델 비율을 적용하지 않는다.
3. 감수분열·수정으로 52개 자손을 만든다. 예측·기대 비율·실제 표본을 비교한다.
4. 손패 8개에서 최대 5개씩 출하한다. 점수는 족보·당도·도구로 계산한다. 선택한 유효 과실 모종 전체를 형질 납품 수량에 센다. 열매 없는 수그루와 특별 규칙으로 무효가 된 모종은 제외한다.
5. 계약 완료 후 돈과 출하 연구 레벨 보상을 받는다. 관찰한 자손 중 번식 가능한 모종을 다음 부모로 선발할 수 있다.
6. 상점의 묶음 선택지는 구입 전에 모두 확인할 수 있다. 구입 후 선택지는 바뀌지 않는다.

출하 기본 4회(전통 팀은 5회), 솎아내기 3회다. 도구와 증축으로 늘릴 수 있다. 온실 기본 6칸이며 새 단원의 필수 재료와 칸은 확정 제공한다. 장인의 비법은 왼쪽부터 발동한다. 학생 정보·계정·서버는 사용하지 않는다.

## 시즌별 유전 과제

| 시즌 | 반드시 다루는 형질 | 확정 제공·도움 |
|---|---|---|
| 1 | 루비·골드 과육, 마지막 계약은 두 색 모두 | RR × rr 첫 교배 시범, 예측·관찰 비교 |
| 2 | 골드·매끈한 껍질과 루비·별무늬 | 독립적으로 전달되는 R·S 예시 |
| 3–4 | 은빛 잎 암그루, 골드·초록 잎 암그루 | 공개된 암그루와 은빛·초록 잎 수그루 |
| 5 | 씨 없는 3배체, 골드 과육 | 4배체 부모와 4n × 2n 예시 |
| 6 | 기본 당도 16 이상, 정상 핵형 골드 | 고당도 계통, 환경 효과와 유전값 구분 |
| 7 | 쓴맛 없는 모종; 편집 팀은 B 기능 제거 1포기 필수 | Bb 연구용 포기와 유전자 가위 |
| 8 | 기본 당도 16 이상 골드와 루비를 함께 납품 | 앞선 선발·교배의 형질 결합 |

특별 주문은 학습 순서에 맞춘다. 초반 균일성 검사 → 성염색체의 열매 검사 → 염색체 단원의 냉해 → 고당도 계약이며 마지막은 품종 박람회다. 과거 저장의 진행 중 시즌은 당시 계약을 유지하고 다음 시즌부터 새 조건을 적용한다.

전체 연대기는 8시즌·24계약, 빠른 연대기는 4시즌·12계약이다. 성염색체(3–4), 염색체 이상(5–6), 유전자 편집(7–8) 단원 게임은 각각 2시즌·6계약이며 해당 재료를 갖춘 상태로 시작한다.

## 운영 방식

| 팀 | 이점 | 제약 |
|---|---|---|
| 전통 육종팀 | 출하 +1 | 유전자 가위·형질전환 사용 불가. 시즌 7은 교배·선발로 해결 |
| 정밀 편집팀 | 유전자 가위로 시작 | 형질전환 사용 불가 |
| 생명공학팀 | 계약 보상 +$1, 형질전환 허용 | 꽃가루 이동을 관찰하고 기술 선택을 돌아봄 |

## 안내와 돌아보기

수업 모드의 첫 교배는 부모와 예측을 채워 주지만 플레이어가 직접 교배를 확정한다. 새 단원의 첫 계약에는 풀이 예시를 제공하고 다음 계약에서는 안내를 줄인다. 교배 도움과 플레이 방법은 계속 열 수 있다.

연구 노트는 관찰 뒤 열린다. 해당 계약의 부모·예측·관찰·납품 기록을 개념 설명과 연결한다. 교사용 안내에서는 전체 개념을 볼 수 있다. 게임 설정과 실제 과학을 나누어 적는다.

결과 화면에는 실제 유전자형, 성공·실패·재도전 비교, 선택의 근거 질문, 연대기별 성찰, 내려받을 수 있는 텍스트 보고서가 있다. 여러 연대기를 독립 저장하며 종료한 판도 다시 열 수 있다. 수업 배정안은 단원 플레이 15~20분 또는 빠른 플레이 25~35분 후 돌아보기 8~10분이다. 학생 대상 소요 시간·학습 효과는 아직 측정하지 않았다.

## 과학 모형의 범위

루미·별다래와 등장인물은 가상이다. 루미의 R 과육색, S 껍질 무늬, B 쓴맛은 단순 우열로 표현한다. R과 S는 서로 다른 염색체에 있다. 당도는 여섯 가산 유전자 자리의 모형이며 실제 과일의 당도는 환경·다수 유전자·상호작용의 영향을 받는다.

별다래의 XY와 X 연관 잎색은 수업용 가정이다. 실제 키위의 성 결정 구조 전체를 나타내지 않는다. 게임은 모든 3배체를 씨 없음·번식 불가로 처리한다. 실제 씨 없는 수박도 열매 발달에는 수분이 필요하다.

꽃가루 이동은 호환되는 비형광 어미와 형광 꽃가루 제공자의 **새 자손 씨**에서 관찰한다. 이미 자란 이웃 식물의 유전자형은 바뀌지 않는다. 사건 확률과 시간은 게임을 위해 압축한 값이다.

## 구현과 검증

Vite·TypeScript·DOM·SVG·WebGL, Vitest를 사용한다. 작물은 생성한 WebP 이미지, 로고는 문자와 CSS로 표시한다. 학생 개인정보·외부 API 없이 시드 난수와 브라우저 저장을 사용한다. 자세한 변경 근거와 검증 범위는 [학습 설계 검토](LEARNING-REVIEW.md)에 기록한다.
