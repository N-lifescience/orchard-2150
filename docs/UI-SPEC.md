# 화면·연출 명세 (UI-SPEC v2)

기준 해상도 1280×720(16:9). 더 크거나 작으면 `#stage`를 CSS transform scale로 맞춘다.
교실 크롬북·태블릿·데스크톱을 모두 지원. 터치 대상 최소 40px. 폰 세로 화면은 "가로로 돌려 주세요" 안내.
한국어는 띄어쓰기 단위로 줄바꿈하고 긴 단어에만 강제 줄바꿈을 허용한다. 설명은 문단으로 나누고 문단 사이 여백을 둔다.
**innerHTML 금지** — 작은 `h(tag, props, ...children)` 도우미로 만든다.

## 0. 쓰는 모듈 (계약만 보고 쓴다)
- `createGame()` 과 콘텐츠 표: `src/game/index.ts` (계약 `src/contract/game.ts`)
- 그림: `src/art/index.ts` (계약 `src/contract/art.ts`) — 카드·아이콘·배경·로고 전부 여기서. UI 는 레이아웃·애니메이션만.
- 소리: `src/audio/index.ts` 의 `audio` (계약 `src/contract/audio.ts`)
- 유전 표시 도우미(읽기 전용 순수 함수): `src/genetics/index.ts` — describeGenotype, inferableLoci, formatGenotype, SPECIES,
  transcribe, templateStrand, translate, analyzeCoding, CODON_TABLE.
- 상태는 절대 직접 고치지 않는다. Game 메서드만 호출하고 subscribe 로 다시 그린다.

## 1. 화면 목록
1. **타이틀** — 과수원 소개와 [새 연대기 시작]을 왼쪽에, ‘내 연대기’ 저장 목록을 오른쪽에 표시한다. [플레이 방법] [연구 노트] [설정] [선생님 안내]를 제공한다.
   새 연대기는 진행 방식 → 플레이 범위 → 운영 팀 → 과수원 이름의 네 단계로 준비한다. 카드를 선택한 뒤 [다음]으로 넘어가며, 뒤로 가도 선택을 유지한다.
   범위는 전체 8시즌·24계약 / 짧은 4시즌·12계약과 단원 게임 2시즌·6계약으로 구분한다. 성염색체는 시즌 3~4, 염색체 수는 5~6, 유전자 편집은 7~8이다. 시즌 1~8 표시에서 선택한 구간을 강조한다.
   운영 팀은 세 가지이며 유전자 편집 단원에서는 해당 팀을 자동으로 지정한다. 이름은 선택 사항이며 최대 12자다. 진행 방식·범위·팀을 확인하고 [플레이 시작]을 누른다.
   저장 카드에는 이름, 상태, 모드, 팀, 현재 시즌·계약, 완료 계약 수와 마지막 저장 시각을 표시한다. 진행 상태에 따라 [이어하기] [재도전 준비] [기록 보기]를 제공하며 삭제 버튼은 분리한다. 새 연대기를 시작해도 기존 기록은 보존한다. 기록은 이 기기 브라우저에 저장한다.
2. **런 화면 (Balatro 배치)**
   - 왼쪽 패널: [홈], 시즌·주문 휘장, 의뢰인 한 줄, **목표 점수와 필수 형질 납품 수량**, **이번 주문 점수**, 족보 이름+레벨,
     **칩(청록 상자) × 배수(자홍 상자)**, 출하·솎아내기 남은 수, 돈, 시즌 진행(주문 3개 점), [주문 정보] [온실] [연구 노트] [설정].
   - 위: 비법 줄(최대 칸 수만큼 자리 표시, **끌어서 순서 바꾸기** — 순서가 점수에 영향), 오른쪽 위 시약 칸.
   - 가운데: 출하된 카드가 놓이는 무대.
   - 아래: 손패 8장 부채꼴(살짝 호), 카드마다 느린 부유(서로 위상 다르게), 마우스 따라 3D 기울기(--rx/--ry),
     선택하면 위로 올라가며 빛 테두리와 짧은 선택 효과를 표시한다. 아래 버튼 [출하] [솎아내기] + 정렬(당도/빛깔). 선택한 카드의 **예상 족보·칩×배수**를 실시간 표시. 출하 가능한 버튼은 밝게 강조한다.
   - 오른쪽 아래: 씨앗 꼬투리(남은 알/52). 누르면 **남은 씨앗의 표현형 분포**(빛깔 4 × 당도 8~20 격자, 수그루 따로) — 비율을 눈으로 보게.
3. **교배 준비 (phase 'cross')** — 이번 주문 카드(목표·보상·보스 규칙 휘장)를 크게. 아래 온실 부모 카드들.
   두 포기 선택(같은 포기 = [자가수분] 버튼). 자손 과육색을 예측해야 교배 버튼이 켜진다. canCross 거절 사유 표시. 퍼넷 노트가 있으면 교배 전 기대 분포 막대그래프.
   [교배하기] → 연출: 두 부모에서 꽃가루 입자가 흘러 가운데서 만나 꼬투리가 생기고, 카드 8장이 차례로 날아옴(deal 소리).
4. **점수 연출 (가장 중요)** — ScoreTrace.steps 를 그대로 순서대로:
   출하 카드가 무대로 이동해 착지 → 족보 이름 크게 등장(칩·배수 상자 튕김) → step 마다: 대상 카드/비법에 `is-trigger`,
   그 위로 떠오르는 숫자(칩 청록 '+14', 배수 자홍 '+4 배수', 곱하기는 더 크게 '×3' + 화면 살짝 흔들림),
   점수 발생 위치에서 해당 칩·배수 상자로 빛 입자가 이동한다. 칩·배수 상자 숫자 굴러 올라감, audio chip(step 번호)/mult/xmult. 마지막에 칩×배수 = 합계가 크게 → 이번 주문 점수로 날아가 더해짐.
   점수와 필수 납품 조건을 모두 달성하면 불꽃 + 배경 pulse + ‘계약 완료’ 배지. 속도 1×/2×/4× (설정), 클릭하거나 Space를 누르면 빨리 감기.
   그 뒤 출하 카드는 오른쪽으로 날아가 사라지고 새 카드가 들어옴.
   장식 효과에는 게임 난수와 별도의 난수를 사용한다. 동작 줄이기·빠른 연출·빨리 감기를 따르며, 연출 종료와 예외 처리에서 임시 요소를 정리한다.
5. **정산 (cashout)** — 줄마다 동전이 튀며 합산, [받기].
6. **선발 (select)** — "이번 주문에서 본 모종 중 한 포기를 온실에 들여요(다음 교배의 부모가 돼요)". 후보 카드들 + 현재 온실.
   가득이면 내보낼 포기를 고르게. 환경 효과(brixMod) 카드엔 "비료·가뭄 효과는 유전되지 않아요" 표식. [건너뛰기].
7. **상점 (shop)** — 위에 비법·시약 칸, 아래 선택 목록 2개·증축 1개, [새로고침 $n], [다음 주문 ▶](다음 주문 미리보기).
   가진 비법은 눌러서 [판매 $n]. 선택 목록은 [구입 전 살펴보기]에서 확인하고, 구입 뒤 동일한 목록에서 고른다.
   식물을 고르는데 온실이 가득이면 내보낼 포기 선택.
8. **온실 보기(모달)** — 부모 카드들 + 공개된 유전자형 + 핵형 그림 + 부모 계보(누구×누구 몇 세대).
9. **편집 작업대(모달, 유전자 가위)** — 대상(온실 포기 또는 손패 카드) → 자리(예 '1번 염색체 · 과육색 유전자(사본 1)') 선택 →
   세 줄: DNA 주형 가닥(templateStrand), DNA 코딩 가닥, **mRNA**(transcribe) — 코돈마다 3글자 묶음과 번호,
   그 아래 **아미노산 칩**(한국어 이름, 종결은 붉은 STOP). 오른쪽에 **유전 부호 표**(64칸, 방금 바뀐 코돈 강조).
   조작: 코딩 가닥의 염기를 눌러 A→T→G→C 순환(치환) 또는 [한 염기 지우기](결실). **한 번에 한 곳만** 바꿀 수 있고 되돌리기 가능.
   바꿀 때마다 analyzeCoding 결과(kind·기능 여부·한국어 note)를 실시간으로 보여 줌. [편집 확정] → applyEdit.
   (정답을 알려 주지 않는다. 도구만 준다.)
10. **개념 카드(발견)** — 점수 연출이 끝난 뒤 pendingDiscoveries 를 하나씩: 카드가 빙글 돌며 등장, 제목, body,
    게임 설정과 실제 과학을 구분해 표시하고, 성취기준 코드를 함께 적는다. [연구 노트에 꽂기] → ackDiscoveries. discovery 소리.
11. **연구 노트** — 왼쪽에 단원별 목차, 오른쪽에 넓은 종이 본문을 배치한다. 두 영역은 따로 스크롤하고 개념을 고르면 본문 첫 줄로 이동한다. 제목은 말줄임 없이 표시한다.
    본문은 발견한 현상 → 실제 과학 설명 → 게임에서 정한 규칙 → 성취기준 → 해당 연대기에서 관찰한 결과 순서다. 부모 유전자형·씨앗 분포·납품 수량을 실제 계약 기록에서 가져온다.
    미발견 개념은 잠겨 있으며 [단원별] [성취기준별]로 목차를 바꿀 수 있다.
12. **끝 (gameover/victory)** — "플레이 기록": 도달 시즌, 계약 완료 수, 재도전 수, 최고 출하 점수, 족보별 횟수, 발견 수,
    **정체 공개**: 온실 모든 포기의 실제 유전자형 + 핵형 + 계보(카드가 뒤집히며 공개),
    철학 성찰 한 줄 질문(03-05): "우리 브랜드는 무엇을 택했고 그 대가는 무엇이었나요?"(입력칸, localStorage 만),
    계약별 부모·예측·관찰·납품·재시도 비교 보고서와 텍스트 저장, [새 연대기] [홈으로]. 완료 기록도 저장 목록에서 다시 연다.
    **계약 검토(review)**는 수업 모드의 실패 화면이다. 조건별 미달 수량과 점수·힌트를 보고 [이 계약 다시 준비]로 계약 시작 상태를 복구한다.
13. **설정** — 음량(전체·음악·효과), 음소거, 연출 속도, 동작 줄이기, 저장 지우기.
14. **선생님 안내** — 이 게임의 개념 ↔ 성취기준 표(GDD 5절), 수업 모드 설명, "학생 개인정보를 수집하지 않아요(모든 기록은 이 기기 브라우저에만)".

## 2. 조작
키보드: 1–8 카드 선택 토글, Enter 출하, D 솎아내기, S 정렬 전환, Esc 모달 닫기, Space 점수 연출 빨리 감기.
마우스/터치: 탭으로 선택, 비법은 끌어서 순서 변경(터치 길게 눌러 끌기).
툴팁: 카드·비법·시약·보스에 마우스를 올리면(터치는 길게) 설명. 카드 툴팁엔 표현형 문장("루비 과육 · 별무늬 · 당도 15°Bx"),
공개됐으면 유전자형, 멘델의 안경이 있으면 inferableLoci 로 확실한 자리만.

## 3. 느낌 (Balatro 에서 배울 것)
- 모든 것이 살짝 움직인다(부유, 흔들림, 숫자 굴러감). 하지만 prefers-reduced-motion / 설정에서 끄면 즉시 멈춘다.
- 버튼은 누르면 눌리는 감(translateY 2px + 그림자 줄어듦). 호버 소리 아주 작게.
- 숫자 표기는 천 단위 쉼표, 큰 수는 '1.2만'.
- 전환은 0.25~0.4s ease-out, 카드 이동은 FLIP(uid 기준으로 이전 위치→새 위치).

## 4. 검증용 손잡이 (필수)
`?debug=1` 이면 `window.__sa = { game, fast(on), autoplay(steps) }` — fast 는 모든 연출 시간을 0 으로. autoplay 는 봇처럼 교배·최선 출하·공방 나가기를 반복.
시드·연대기 길이·진행 방식 선택, [검증 시작] [자동 진행] [빠른 연출]을 화면에 제공한다. 도구가 차지하는 높이를 제외하고 게임 화면을 맞춘다.
QA 가 백그라운드 탭(초당 몇 프레임)에서도 게임을 끝까지 진행해 볼 수 있어야 한다. 연출은 requestAnimationFrame 대신
Web Animations API + setTimeout 기반으로 끝이 보장되게(애니메이션이 멈춰도 게임 진행이 막히지 않게 `finished` 에 타임아웃 병행).
