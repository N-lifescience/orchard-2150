# 반응형 화면과 첫 계약 실습

2026-10-02 변경 및 검증 기록.

## 진행 방식과 운영팀

- **재도전 허용**: 실패한 계약부터 다시 준비한다. 이전 계약의 보상과 온실을 유지한다.
- **실패 시 종료**: 계약을 한 번 실패하면 해당 연대기가 끝난다. 종료 기록을 다시 볼 수 있다.
- 두 방식 모두 중간 저장과 이어하기를 지원한다. 내부 저장 식별자는 그대로 두어 기존 연대기를 불러온다.
- **교배·선발팀**: 계약마다 출하 1회 추가. 편집·형질전환 도구 사용 불가.
- **유전자 편집팀**: 유전자 가위 1개로 시작. 외래 유전자 도입 불가.
- **형질전환팀**: 해파리 유전자 비법으로 시작하며 계약 보상 $1 추가. 형질전환 도구는 공방에서 구한다. LMO 검사와 꽃가루 유출의 대가를 함께 설명한다.

## 화면

- 1100px 이하 또는 터치 기기는 고정 데스크톱 화면을 축소하지 않고 세로 흐름으로 재배치한다.
- 본문 16px, 주요 터치 버튼 최소 44px. 휴대폰 손패는 2열 격자로 표시하고 형질을 카드 아래에 풀어 쓴다.
- 교배·출하·정산·선발·공방의 이전 화면은 전환 중 숨겨 겹침을 방지한다.
- 데스크톱 게임 영역의 숨은 스크롤을 차단해 팀 선택 화면이 위로 잘리는 문제를 해결했다.
- 화면이나 준비 단계가 바뀌면 처음으로 이동한다. 튜토리얼에서는 안내할 실제 조작 영역으로 이동하고, 대화창이 대상을 가리지 않도록 위치를 정한다.
- 비법·시약은 그림과 이름이 있는 작은 도구 버튼으로 표시한다. 선반의 높이는 고정하고, 도구가 많으면 선반 안에서만 가로로 넘겨 본다.
- 주문은 왼쪽 종이 장부에, 교배와 출하는 가운데 가죽 작업대에 배치한다. 교배 화면의 중복 주문 카드는 제거했다.
- 모달 폭을 화면 안으로 제한한다. DNA·씨앗 분포처럼 넓은 자료는 해당 영역 안에서만 가로 스크롤한다.
- 연구 노트는 태블릿에서 목차와 본문을 나란히, 휴대폰에서 위아래로 배치한다. 기록 선택 시 본문으로 이동한다.
- 자가수분 기록은 두 부모 식별자가 같은 실제 계약 기록만 연결한다.

## 실습

홈의 **튜토리얼**을 누르면 별도 연대기가 바로 시작된다. 기존 연대기는 저장 목록에 남는다.

레아의 큰 캐릭터 그림과 대화창이 목표·제약·메뉴·도구부터 부모 선택·예측·교배·관찰·출하·정산·선발·공방까지 20단계를 안내한다. 현재 설명하는 실제 버튼이나 카드에 빛나는 테두리를 두고, 나머지 화면은 어둡게 한다. 설명 대상과 대화창만 조작할 수 있고, 실제 선택과 게임 상태에 따라 다음 단계로 넘어간다. 카드 선택은 한 장씩 안내한다.

연구 노트나 꼬투리 자료 등의 창을 열면 안내를 잠시 숨기고, 창을 닫으면 다시 보여 준다. 조작 위치를 다시 보여 주는 버튼과 안내 중단 버튼도 제공한다. 작은 화면에서는 대화창의 설명을 스크롤할 수 있고, 실제 카드가 위쪽에 보이도록 이동한다.

도중에 홈으로 가거나 새로고침해도 같은 단계에서 이어할 수 있다. 완료하면 **이 과수원에서 계속하기** 또는 **새 과수원 시작**을 고른다. 계속하기는 보상과 선발 모종을 유지하며 두 번째 계약으로 이어진다. 새로 시작하기는 기존 튜토리얼 연대기를 보존하고 새 연대기 준비 화면으로 이동한다. 이전 버전의 실습 저장도 불러올 수 있다.

## 예상 시간

쉬는 시간을 제외한 안내치이며, 선택·읽기·재도전 속도에 따라 달라진다. 실제 사용자 측정치로 표시하지 않는다.

| 범위 | 재도전 허용 | 실패 시 종료 |
|---|---|---|
| 전체 연대기 | 80~120분 | 60~90분 |
| 짧은 연대기 | 40~60분 | 30~45분 |
| 성염색체 | 20~30분 | 15~25분 |
| 염색체 이상 | 20~35분 | 15~30분 |
| 유전자 편집 | 25~40분 | 20~35분 |
| 첫 계약 실습 | 5~8분 | — |

선택 카드, 시작 전 확인, 저장 목록에 표시한다. 저장 목록의 시간은 남은 시간이 아닌 **전체 예상**이다.

## 검증

- `npm run typecheck`: 통과.
- `npm run build`: 통과.
- `npm test`: 12개 파일, 219개 테스트 통과. 새 안내 단계·저장 호환성·재도전·저장 격리·손상 저장·튜토리얼 이후 진행을 포함한다.
- 이번 안내창 검증 크기: 320×568, 390×844, 1024×768, 1280×720. 이전 반응형 검증에는 768×1024도 포함했다.
- 첫 계약을 실제로 두 번 완료했다. RR×rr 예측·교배, 루비 52알 관찰, 카드 5장 출하를 진행했다. PC에서는 2912점, 휴대폰에서는 404점으로 목표 300점과 루비 납품 3포기를 충족했고, $9 정산을 확인했다.
- 모종 선발 후 같은 과수원에서 이어하기와 새 과수원 시작하기를 각각 확인했다. 이어하기는 돈 $13과 선발한 모종을 유지했다.
- 안내 도중 홈 복귀·이어하기, 연구 노트 열기·닫기, 꼬투리 열기·닫기, 발견 기록 저장을 확인했다. 모달을 열 때 안내가 잠시 사라지고 닫으면 돌아온다.
- 390px에서 안내창과 목표·메뉴·도구·손패·출하 버튼의 겹침을 측정해 0임을 확인했다. 320px에서 부모 카드 전체가 대화창 위에 보이도록 수정하고 다시 확인했다.
- 비법 2개·시약 2개가 있는 저장 게임에서 상세창과 시약창을 열었다. PC와 휴대폰 모두 선반 내부 스크롤을 사용하며 페이지의 가로 넘침이 없었다.
- 정렬하지 않은 손패는 당도·빛깔 버튼 모두 미선택이다. 당도를 누른 뒤 표시가 켜지고 실제 카드가 15, 14, 14, 13, 13, 12, 12, 12°Bx 순서로 바뀌는 것을 확인했다.
- 크기를 조절한 브라우저 검증이다. 실제 iOS·Android 기기의 터치와 브라우저 차이는 별도 기기 검증 대상이다.
