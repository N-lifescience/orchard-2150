# 오차드 2150 아트 교체

## 적용한 스킬

`skills.sh`에서 후보를 찾고 AG Kit 저장소의 원문을 읽어 적용했다.

- [game-art](https://github.com/vudovn/ag-kit/blob/main/.agents/skills/game-development/game-art/SKILL.md): 화풍 통일, 이미지 시트 구성, 작은 크기의 실루엣, 색상 대비, 파일 관리.
- [game-design](https://github.com/vudovn/ag-kit/blob/main/.agents/skills/game-development/game-design/SKILL.md): 행동과 결과가 이어지는 카드 표현, 육종 도구와 카드 효과의 연결.

전역 설정이나 에이전트 규칙을 설치하지 않았다. 이번 그림 작업에 스킬의 지침을 적용했다.

## 제작 기준

- 의뢰인을 이름과 얼굴로 기억할 수 있다. 사람의 직업과 도시를 바탕으로 옷과 소품을 정했다. 인물은 모두 가상이다.
- 비법과 시약은 각 효과를 떠올릴 수 있는 도구나 소재로 그렸다. 실제 염색체 수나 유전자형은 생성 그림으로 표현하지 않는다.
- 청록색 그림자, 호박색 빛, 황동·가죽·유리의 질감을 공유하는 채색 일러스트다.
- 이름과 효과, 가격, 당도, 유전자형은 HTML의 실제 글자다. 생성 그림에는 문자를 넣지 않았다.
- 카드 테두리, 로고 문장, 메달, 봉투도 비트맵으로 교체했다. 작은 기능 표식은 문자와 CSS 도형, 핵형은 데이터에 따라 그리는 Canvas다.

새 그림은 `src/art/assets/generated/`에 포함되어 있다. 생성 방식은 내장 `imagegen`이다. 큰 레아 그림은 약 0.31MB다. 시트에서 실제로 관찰한 칸 경계를 사용하고, 그림 비율을 유지해 잘라 표시한다. 파일명을 Vite에서 해시 처리하고 상대 배포 경로를 사용한다.

초상화는 주문·다음 주문·주문 정보·특별 계약 화면의 의뢰인과 연결했다. 레아는 튜토리얼 안내에, 시작 품종의 육종가는 부모 카드에 표시했다.

전체 그림 검토 페이지는 `art-review.html`이다. 개발 서버에서 `/art-review.html`을 열면 실제 카드 컴포넌트로 인물과 그림을 모아 볼 수 있다. 이 검토 페이지는 기본 배포 진입점에 추가하지 않았다.
