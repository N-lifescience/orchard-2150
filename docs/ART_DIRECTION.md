# 2026-10-23: 영상에서 이어지는 밤 온실

현재 게임 UI는 소개 영상의 HUD 문법을 따른다. 갈색빛 검정 바탕, 아이보리 글자와 얇은 선, 주 행동과 현재 위치에만 주황 `#ff6b3d`를 쓴다. 색 토큰 표와 화면별 배치 원칙은 [UI-SPEC.md](UI-SPEC.md)의 「소개 영상 HUD 체계」를 기준으로 한다.

| 모티프 | 표현 |
| --- | --- |
| 인물 서류 | 어두운 사각 사진, 모서리 조준선, 구멍과 바코드가 있는 이름 꼬리표, 도시와 직업 한 줄 |
| 작물 카드 | 어두운 유리 판과 실제 작물 그림, 살아 있는 이름표, 형질과 공개 유전자형 |
| 조건과 결과 | 점선 영수증과 고정폭 카운터, 정산의 작은 톱니 아랫단 |
| 운영 팀 | 씨앗 꼬리표 이름과 도구 그림 |
| 엘레나의 기록 | 어두운 바탕 위 작은 종이와 Gowun Batang, 내용별 쪽 넘김 |

큰 양피지 판, 나무 테두리, 초록 펠트, 금박 버튼, 광택은 사용하지 않는다. `frame.webp`를 카드에서 감추고 라이브 글자와 CSS 선으로 바꾼다. 원본 그림 파일은 이 UI 작업에서 수정하지 않는다.

`public/explain/bg-greenhouse.webp`와 `bg-bench.webp`를 어둡게 깔고 비네팅을 더한다. 장면 영상과 전체 화면 서막은 검정에서 0.5초 디졸브로 잇고 서막 뒤로 게임판이 보이지 않게 한다. 대사는 아래 자막, 인물 초상은 작은 사진 카드다. 이야기와 영상 위에 큰 backdrop-filter나 합성 모드를 추가하지 않는다. 동작 줄이기 설정을 따른다.

형질 전용 그림 연결은 작업 B에서 `traitBadge()`로 통일한다. 파일명은 `public/explain/manifest.json`, 앱 경로는 문서 기준 `explain/<파일명>.webp`다. 현재 형질 꼬리표의 작은 그림은 기존 `plantImageUrl()`의 표현형 예시이며 유전자형이나 수량을 표현하지 않는다.

아래는 이전 그림 제작 이력이다. 현재 UI 재료와 충돌하는 항목은 위 기준으로 대체한다.

# 오차드 2150 아트 교체

## 적용한 스킬

`skills.sh`에서 후보를 찾고 AG Kit 저장소의 원문을 읽어 적용했다.

- [game-art](https://github.com/vudovn/ag-kit/blob/main/.agents/skills/game-development/game-art/SKILL.md): 화풍 통일, 이미지 시트 구성, 작은 크기의 실루엣, 색상 대비, 파일 관리.
- [game-design](https://github.com/vudovn/ag-kit/blob/main/.agents/skills/game-development/game-design/SKILL.md): 행동과 결과가 이어지는 카드 표현, 육종 도구와 카드 효과의 연결.

전역 설정이나 에이전트 규칙을 설치하지 않았다. 이번 그림 작업에 스킬의 지침을 적용했다.

## 제작 기준

- 의뢰인을 이름과 얼굴로 기억할 수 있다. 사람의 직업과 도시를 바탕으로 옷과 소품을 정했다. 인물은 모두 가상이다.
- 비법과 시약은 각 효과를 떠올릴 수 있는 도구나 소재로 그렸다. 실제 염색체 수나 유전자형은 생성 그림으로 표현하지 않는다.
- 청록색 그림자, 호박색 빛, 황동·가죽·유리의 질감을 공유하는 채색 일러스트다.
- 이름과 효과, 가격, 당도, 유전자형은 HTML의 실제 글자다. 생성 그림에는 문자를 넣지 않았다.
- 카드 테두리, 로고 문장, 메달, 봉투도 비트맵으로 교체했다. 작은 기능 표식은 문자와 CSS 도형, 핵형은 데이터에 따라 그리는 Canvas다.

새 그림은 `src/art/assets/generated/`에 포함되어 있다. 생성 방식은 내장 `imagegen`이다. 큰 레아 그림은 약 0.31MB다. 시트에서 실제로 관찰한 칸 경계를 사용하고, 그림 비율을 유지해 잘라 표시한다. 파일명을 Vite에서 해시 처리하고 상대 배포 경로를 사용한다.

초상화는 주문·다음 주문·주문 정보·특별 계약 화면의 의뢰인과 연결했다. 레아는 튜토리얼 안내에, 시작 품종의 육종가는 부모 카드에 표시했다.

전체 그림 검토 페이지는 `art-review.html`이다. 개발 서버에서 `/art-review.html`을 열면 실제 카드 컴포넌트로 인물과 그림을 모아 볼 수 있다. 이 검토 페이지는 기본 배포 진입점에 추가하지 않았다.

## 인물 포즈 수정 · 2026-10-02

인물 21명의 자세·시선·각도를 다시 생성했다. 기존 인물의 얼굴, 옷, 소품과 각 칸의 순서를 유지하고 정면·측면·돌아보기, 손짓·필기·과일 고르기 등 서로 다른 동작을 지정했다. 씨앗 문장 칸은 유지했다.

- `people-a.webp`: 9명, 387,502바이트.
- `people-b.webp`: 9명, 364,216바이트.
