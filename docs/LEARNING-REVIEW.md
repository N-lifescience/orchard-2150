## 검토 기준과 판정

사용자가 폴더에 둔 `학습게임_설계이론.html`의 점검 질문을 적용했다. 해당 파일은 참고용으로만 읽었으며 저장소에 포함하지 않았다. 문서의 연구 효과 수치는 이번 검토에서 재검증하거나 게임의 학습 효과로 인용하지 않았다.

**판정:** 유전 형질을 계약 완료의 필수 조건으로 만들면서, 기존 점수 중심 게임을 유전 학습 과제와 연결했다. 관찰·예측·부모 선택·재도전의 근거도 남긴다. 학생 대상 효과 검증을 마친 게임이라는 뜻은 아니다.

## 검증 근거

- 로컬 타입 검사·프로덕션 빌드 통과.
- Vitest 206개 통과. 높은 점수로 형질 조건을 건너뛰지 못함, 실패 때 소모한 가위·부모 유전자형 복원, 기본 당도와 비료 효과 구분, 필수 재료, 구매 전후 선택 목록 일치, 꽃가루 이동 뒤 성체 유지, 옛 저장 호환, 연대기별 성찰 분리 등을 검사했다.
- 동일한 선택 전략으로 각 경우 시드 1–10을 실행했다. 수업 모드, 계약당 최대 재시도 2회 조건이다. 완료한 계약은 점수와 형질 수량을 모두 충족했는지 재확인했다.

정밀 편집 시드 6은 시즌 4의 점수가 부족해 검증의 재시도 상한에서 멈췄다. 필수 형질은 충족했다. 실제 수업 모드는 재시도를 더 허용한다. 봇은 유전자형을 읽는 검증 도구이므로 이 비율은 학생 난이도나 학습 성취도를 뜻하지 않는다.

실제 화면에서 첫 교배 시범·예측·출하 진척을 직접 조작했다. 한 포기씩 출하해 실패를 만들고 조건별 피드백·계약 재도전을 확인했다. 화면 자동 진행으로 빠른 4시즌 12건과 전체 8시즌 24건을 완료했고, 끝난 연대기를 홈에서 다시 열어 보고서를 확인했다. 성염색체·염색체 이상·유전자 편집 단원도 각각 6건 완료를 확인했다. 편집 작업대에서는 B의 5번째 염기를 C에서 A로 직접 바꾸어 UCA → UAA와 단백질 기능 상실을 확인했다. 편집 단원 완료 뒤 Chrome에서 텍스트 보고서가 다운로드 폴더에 저장된 것을 확인했다. 자동 진행은 교배·출하 화면 메서드를 사용하며 모든 동작을 사람이 일일이 누른 검증은 아니다.

## 실제 과학과 구분한 부분

꽃가루로 옮겨온 유전 정보는 새 씨의 유전자형에 기여하며, 이미 자란 모체의 과육·유전자형을 바꾸지 않는다. 이 구분에 맞춰 유전자 이동 사건을 수정했다. [USDA ARS의 과육과 씨 설명](https://www.ars.usda.gov/oc/br/plumpox/more5/)

4배체와 2배체의 교배로 3배체 씨 없는 수박을 만들 수 있지만, 열매 발달에는 별도의 수분이 필요하다. 게임의 모든 3배체를 씨 없음·번식 불가로 처리하는 규칙은 단순화다. [University of Georgia Extension의 설명](https://site.extension.uga.edu/gardener/2022/06/what-do-seedless-watermelons-and-mules-have-in-common/)

루미·별다래, XY 잎색 모형, 여섯 가산 당도 자리, 사건 확률과 성장 시간은 가상 또는 압축된 모형이다. 실제 생물 전체에 그대로 적용하지 않도록 연구 노트와 보고서에 범위를 표시했다.

## 장점과 남은 한계

장점은 원하는 유전 형질을 만들고 선발하는 행동이 승리 조건과 직접 연결된다는 점이다. 실패 뒤 관찰을 보존하고 같은 조건에서 선택을 바꿀 수 있으며, 단원 게임으로 수업 범위를 좁힐 수 있다.

전체 연대기는 한 차시에 모두 끝내는 구성으로 권하지 않는다. 단원 또는 빠른 연대기에 수업 시간을 배정하고 돌아보기 8~10분을 남긴다. 표시한 시간은 배정안이며 학생 대상 측정값이 아니다.

카드 점수 규칙에 익숙해지는 시간과 유전 내용을 추론하는 시간이 함께 필요하다. 교사는 첫 교배를 함께 해 보고, 학생이 사용한 부모의 공개 정보와 실제 자손 수를 근거로 설명하도록 도와야 한다. 선택을 시행착오로만 반복해도 일부 계약을 해결할 수 있으므로 성공 자체를 개념 이해의 증거로 삼지 않는다.

다음 교육적 검증은 학생 시범 수업에서 풀이 시간·잘못된 일반화·재도전 때 바꾼 선택을 관찰하고, 게임 밖의 새로운 교배 문제와 사후 토론으로 전이를 확인하는 것이다. 학생 대상 검증은 이번 코드 수정의 결과에 포함되지 않는다.
