## 수정한 오류

1. 기존 저장이 있으면 최신 저장이 실패해도 홈 이동을 허용하던 문제를 고쳤다. `save()`가 이번 저장의 성공 여부를 반환하고, 실패하면 최근 진행 손실을 안내한다. 저장 용량 오류 중에도 플레이는 유지하고 마지막 저장은 보존하는 회귀 테스트를 추가했다.
2. 320px 편집 작업대에서 네 버튼이 좁은 한 줄에 압축되던 문제를 고쳤다. 작은 화면에서는 두 줄로 배치한다.
3. DNA 염기를 조작한 뒤 화면을 다시 그리면서 키보드 초점이 사라지던 문제를 고쳤다. 수정한 염기에 초점을 유지한다.
4. 종료 화면의 납품 기록 끝에 남던 구분점을 제거했다.

## 검증 결과와 범위

- Vitest: 12개 파일, 221개 테스트 통과. 기존 219개에 저장 실패 회귀 테스트 2개 추가.
- `npm run build`: TypeScript 검사와 프로덕션 빌드 통과.
- 실제 편집 화면: 320/375/768/1024/1440px 확인. 문서의 가로 넘침과 잘린 버튼 없음. DNA 서열 영역은 의도한 내부 가로 스크롤을 유지한다.
- 염기 변경 직후 실제 초점이 `5번째 염기 A`에 남는 것을 DOM에서 확인했다.
- 브라우저 콘솔에서 오류·경고 없음. 완료 화면의 이미지 로드 실패 없음.
- 저장 실패 안내는 `humanize-korean`의 light·보수 경로 적용. 원문 49자→50자, 변경률 2.0%, 자체검증 6/6, 등급 B, 검증 게이트 통과.
- 보고서 화면과 계약별 기록은 확인했다. 앱 내 브라우저의 다운로드 완료 이벤트가 시간 초과되어 이번 검증에서는 파일 내려받기 완료를 확인하지 못했다.

검증 화면과 DOM 기록은 로컬 `_workspace/playtest-2026-10-03/`에 보관했다. 배포 환경의 동작과 실제 학생 플레이 시간은 이번 검증 범위에 포함하지 않았다.
