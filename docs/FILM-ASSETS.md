# 영상·그림 파일 목록 (public/film)

코드가 찾는 미디어 파일 전부다. 모두 `public/film/`에 두면 Vite가 `dist/film/`으로 그대로 복사한다(`base: './'`, 상대 경로 `film/…`).
CSP가 `default-src 'self'`라서 **같은 출처의 파일만** 재생한다. 외부 주소·`blob:` 영상은 쓰지 않는다.

파일이 없거나 깨져도 게임은 멈추지 않는다. 아래 「없을 때」 열의 동작으로 넘어간다.

| 경로 | 쓰는 곳 | 목표 길이·크기 | 없을 때 |
|---|---|---|---|
| `film/intro.mp4` | 처음 접속할 때 제목 화면보다 먼저 나오는 이야기 영상(`src/ui/story/introFilm.ts`). 기본 음소거, 「소리 켜기」·「건너뛰기」 상시 | 30.0초, 6초 장면 5개 + 0.5초 디졸브. 1280×720 24fps H.264 + AAC | 바로 제목 화면(처음 온 사람은 이어서 첫 계약 튜토리얼). 본 것으로 기록하지 않아 파일을 넣으면 다음 접속에 나온다 |
| `film/intro-poster.webp` | 소개 영상 포스터, 동작 줄이기일 때의 정지 화면, 서막 대화창 위 장면 그림 | 16:9 정지 그림(영상 3구간 발렌시아 밤 온실 장면 권장) | 포스터 없이 어두운 바탕 + HUD, 대화창은 그림 없이 표시 |
| `film/title-loop.mp4` | 제목 화면 뒤 반복 배경(`src/ui/story/titleLoop.ts`). 항상 무음 | 7초, 처음과 끝이 이어지는 반복 영상(소리 없음). 1280×720 | 기존 WebGL 배경을 그대로 쓴다(동작 줄이기에서도 WebGL) |
| `film/scene-vault.mp4` / `.webp` | 시즌 1 시작 「금고가 열리던 날」 ① 금고가 처음 열린다 | 8초(환경음) / 정지 그림 1장 | 영상 → 정지 그림 → 둘 다 없으면 조용히 건너뛰고 대화로 |
| `film/scene-vine.mp4` / `.webp` | 시즌 4 시작 ② 별다래 첫 열매 | 8초(환경음) / 1장 | 위와 같음 |
| `film/scene-frost.mp4` / `.webp` | 시즌 5 시작 ③ 서리 내린 온실의 밤 | 8초(환경음) / 1장 | 위와 같음 |
| `film/scene-offer.mp4` / `.webp` | 시즌 7 시작 ④ 돔 광고판과 인수 제안 | 8초(환경음) / 1장 | 위와 같음 |

장면 영상의 정지 그림(`.webp`)은 대화창 위 장면 그림으로도 다시 쓴다(시즌 1·4·5·7).

## 공통 규칙

- **영상 안에 글자를 넣지 않는다.** 연도·꼬리표·바코드·영수증·카운터·자막·로고는 모두 HTML로 얹는다(`src/ui/story/script.ts`의 `INTRO_CUES`, `src/game/story.ts`의 `SCENES[].captions`). 바코드는 장식용 SVG다.
- 인코딩 권장: H.264(High) MP4, `yuv420p`, `+faststart`, **원본 프레임률 그대로(Veo는 24fps)**. 24fps 원본을 30fps로 바꾸면 4프레임마다 한 장이 겹쳐 떨린다(2026-10-23 전 파일을 24fps로 되돌림, 옛 파일은 `_workspace/film/build/30fps-2026-10-23/`). 소개 영상 4~8MB, 장면 영상 1~3MB, 반복 영상 1~2MB 안팎.
  WebM만 있으면 Safari에서 재생되지 않을 수 있다. 정지 그림은 WebP(품질 80 안팎, 1600px 너비 권장).
- 소리: 소개·장면 영상은 기본 음소거. 「소리 켜기」 설정은 모든 영상이 함께 쓰고 이 기기에만 저장한다(`seed-atelier-2150:film-sound:v1`). 영상 소리를 켜면 게임 배경음은 잠시 멈춘다.
- 동작 줄이기(시스템 설정 또는 게임 설정): 소개 영상은 포스터 + 고정 HUD + 「계속」, 장면은 정지 그림 + 「계속」, 제목 반복 영상은 재생하지 않는다.
- 첫 장면을 6초 안에 그리지 못하면(소개) 또는 5초 안에(장면) 불러오기에 실패한 것으로 보고 다음 단계로 넘어간다.

## 소개 영상 HUD 시간표 (실제 영상 기준, 30.0초 · 128 BPM)

실제 `intro.mp4`는 6초 장면 다섯 개를 0.5초 디졸브로 잇는다. 장면 안에서는 끊지 않고 원본 클립(Veo 8초, 24fps)의 1.0초부터 이어 쓴다. 24fps 그대로 인코딩한다(30fps로 바꾸면 4프레임마다 한 장이 겹쳐 화면이 떨린다). 24초에 음악 강세가 있고 29.3초부터 어두워진다. 다시 만들 때는 `_workspace/film/build/render-intro.sh`를 쓴다.
실제 영상 길이가 10~120초면 시간표 전체를 같은 비율로 늘이거나 줄인다(`cueScale`). 얼굴과 금고 서랍을 가리지 않도록 자리를 정했다.

| 구간 | 장면 | HUD (자리) |
|---|---|---|
| 0–6초 | 회색으로 말라 가는 클론 과수원, 2~4초 연기 같은 병해 | 0.3초 「2120 · 클론 붕괴」(위), 2초 꼬리표 「품종 1 · 클론」(왼쪽), 4초 영수증 「유전자형 일치 100%」(오른쪽) |
| 6–12초 | 흰 돔 농장, 빈 광고판, 자기부상 열차 | 6.1초 「2150 · 모노그로브 돔」(위), 6.6초 큰 글자 「같은 것이 안전하다.」(가운데), 8초 꼬리표 「모노그로브 · 클론 공급」(왼쪽) |
| 12–18초 | 레아가 밤의 온실 문을 열고 불이 켜짐(레아는 왼쪽·가운데) | 12.1초 「2150 · 발렌시아」(위), 12.4초 「오차드 · 문 닫음」 → 14초 「오차드 · 불 켜짐」(오른쪽) |
| 18–24초 | 손이 놋쇠 금고 서랍을 엶(서랍이 화면 대부분) | 18.1초 「씨앗 금고 · 서랍 1 / 8」(위 왼쪽), 18.6초 꼬리표 「엘레나 로시 · 계통 R-07」(위 오른쪽) |
| 24–30초 | 붉은 꽃과 흰 꽃 사이의 꽃가루, 다양한 모종과 열매 | 24초 「시즌 01 / 08」(위), 카운터 「자손 0 → 52」(아래 왼쪽), 24.3초 영수증 「계약서 01 · 루비 과육 3개체 · 300점」(오른쪽), 26초 끝 문장 「씨앗 하나에, 쉰두 가지 미래.」(꽃 아래), 27.9초 로고 ORCHARD 2150(아래) |

장면 영상의 자막은 기본으로 왼쪽 아래에 둔다. `scene-offer`는 아래쪽에 봉투와 노트가 있어 위쪽에 둔다(`captionPlace: 'top'`).
실제 영상 오른쪽 아래 구석에 생성 도구 표시(Veo)가 작게 보이는 컷이 있다. 「건너뛰기」 단추가 대부분 가리지만, 원본에서 지우는 편이 낫다.

장면 영상 브리프: O-C1 금고 · O-C2 덩굴 · O-C3 서리 · O-C4 제안 · O-C5 박람회, 결말 그림 O-E (`_workspace/film/briefs/`).

## 확인 방법

- 개발 서버에서 `?intro=1`을 붙이면 본 기록과 상관없이 소개 영상을 다시 연다. 제목 화면의 「소개 영상 다시 보기」도 같다.
- `?debug=1`에서는 `window.__sa.intro()`, `__sa.ending()`, `__sa.failure()`, `__sa.quiz(시즌)`으로 연출만 따로 열 수 있다.
- 기록 지우기(선생님 안내 → 이 기기 기록 모두 삭제)는 소개 영상 시청 기록·대화 수·영상 소리 설정도 함께 지운다.
