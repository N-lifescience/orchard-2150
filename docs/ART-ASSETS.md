# 작물 이미지

게임 카드의 작물 그림은 `src/art/assets/`의 투명 배경 WebP 16장입니다. 원본 생성 이미지는 2026-09-30에 제작했으며, 웹용으로 축소·압축했습니다. 로딩에 실패하면 `src/art/fruit.ts`의 SVG가 대체 그림으로 표시됩니다.

## 생성 지시

- **루미:** 가상의 둥근 과일을 정면에서 본 고품질 식물 도감 삽화. 루비색/금색 과육, 매끈한 껍질/뚜렷한 별무늬가 카드 크기에서도 구별되도록 각 조합을 별도로 제작. 투명 배경, 글자·테두리·그림자 없음.
- **별다래 암그루:** 털이 있는 타원형 과일과 단면, 두 잎을 함께 보여 주는 사실적인 식물 도감 삽화. 루비색/금색 과육과 초록색/은빛 잎의 네 조합을 각각 제작. 투명 배경, 글자·테두리 없음.
- **별다래 수그루:** 수술이 보이는 다섯 꽃잎의 꽃과 두 잎. 루비색/금색 꽃잎과 초록색/은빛 잎의 네 조합을 각각 제작. 암그루 열매와 혼동되지 않도록 열매 없음.
- **씨 없는 별다래:** 암그루의 네 조합을 원본으로 편집. 단면의 씨와 씨방을 없애고 과육과 작은 연한 중심부로 채움. 나머지 색, 잎, 구도는 유지.

모든 형질은 `src/art/plantImages.ts`에서 표현형에 맞는 파일로 연결합니다.
